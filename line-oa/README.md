## 一、LINE 官方帳號申請步驟（約 15 分鐘）

「LINE@」現在的正式名稱是「LINE 官方帳號」，申請免費。

1. 手機下載 **LINE Official Account** App，用自己的 LINE 帳號登入。
2. 點「建立帳號」，依序填入：
   - 帳號名稱：`鄭菀之｜紫微斗數`
   - 業種：大分類選「個人」或「生活服務」，小分類選「占卜」（如果有的話）
3. 建好後進入「設定 → 帳號設定」：
   - **大頭貼**：上傳 `images/avatar.png`
   - **狀態消息**（最多 20 字）：`看懂風向，走對方向｜命盤解讀預約`
   - **封面**：到「主頁」編輯，上傳 `images/cover.png`
4. 把「加入好友的歡迎訊息」和「自動回應訊息」設好，文案見下方第四節。
5. 到「增加好友 → 行銷素材」下載 **QR Code**。把它存進手機相簿，活動現場直接給人掃。
6. 建議去「設定 → 回應設定」開啟 **聊天** 模式，客人才能一對一私訊你預約。
7. 選用：想讓 ID 好記（例如 `@wanchih`），可以購買「專屬 ID」，一年約 NT$720。沒買的話，系統會給一組隨機 ID。

> 免費方案每月可以主動推播 200 則訊息。一對一聊天和自動回覆不算在這 200 則裡面，剛開始用免費方案就夠了。

## 三、主持人介紹詞（給朋友用）

> 接下來要介紹我的好朋友鄭菀之，一位紫微斗數命理師。
> 紫微斗數用你出生的年月日時排出一張命盤，看得出你的個性、天賦，也看得出每個階段的運勢起伏。
> 菀之常說：「命盤就像風向標，它告訴你風從哪裡來，但要往哪走，還是你自己決定。」
> 所以菀之不嚇人、不說死，而是幫你看清楚風向，找到最順的那條路。
> 今天有興趣的朋友可以掃菀之的 LINE 聊聊，一對一解讀一小時三千元。

五句話，大約 40 秒。如果主持人時間很緊，只唸第 1、3、5 句就可以。

## 四、LINE 自動回覆文案（直接複製貼上）

### 加入好友歡迎訊息
```
嗨 {好友的顯示名稱}，謝謝你加入 🌬️
我是菀之，紫微斗數命理師。

命盤就像風向標，告訴你風從哪裡來；
要往哪裡走，選擇在你。

📌 欽天門紫微斗數・一對一線上解盤｜60 分鐘 NT$3,000
（真人解讀，非 AI）
想預約的話，直接傳訊息給我這三件事：
1. 國曆生日（年/月/日）
2. 出生時間（越精準越好）
3. 性別與出生地

我會盡快回覆你可以的時段 ✨
```
（歡迎訊息後面可以再加一則圖片訊息，放 `price.png`）

### 關鍵字自動回應
| 關鍵字 | 回覆 |
|---|---|
| 價格、價錢、多少、費用 | `欽天門紫微斗數一對一線上解盤，60 分鐘 NT$3,000，全程線上視訊，真人解讀非 AI。想預約請傳：國曆生日、出生時間、性別、出生地 🙏`（加上 `price.png`） |
| 預約 | `好的！請提供：① 國曆生日 ② 出生時間 ③ 性別 ④ 出生地，以及你方便的日期時段，我確認後回覆你 ✨` |
| 時辰、不知道時間 | `出生時間不確定也沒關係！可以先問問家人，或查出生證明。真的查不到的話，解讀時我會帶你一起推敲可能的時辰。` |
